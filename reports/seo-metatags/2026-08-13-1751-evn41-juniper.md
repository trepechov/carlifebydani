## Recommendation

**Focus keyphrase:** `Tesla Model Y Juniper отлагане`

Deliberately narrow. It describes the one thing this episode covers that 6165 does not (6165
is about the European *presentation*; this is about the *delay*), and it carries no measured
demand of its own — so it cannot cannibalise. The realistic value of this page is CTR on its
navigational query, not new topical ranking.

**`EVN41` must stay in the title.** It is 100% of this page's impressions. Stripping the
episode code here would be the opposite of the right move — unlike post 7333, where the
`#EV114` prefix appeared in zero queries.

**Honest expectation:** position 2.7 with 4.62% CTR is genuinely below the 10–15% norm for
that rank, so a meta description should help. But the ceiling is 65 impressions per quarter.
This is a small, cheap win — **not** where the next hour of effort belongs (see below).
