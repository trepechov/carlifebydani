# Competitor & Keyword Gap Reports — carlifebydani.com

Dated snapshots of the Bulgarian organic competitive landscape: who ranks for what,
and which topic clusters carlifebydani.com is absent from.

These are **generated artifacts**, not documentation. Each file is the output of a
single point-in-time data pull and is not refreshed automatically — the date in the
filename is the date the data was pulled.

## Source

Semrush (BG desktop database) via the Semrush MCP server. Reports used:
`domain_organic_organic` for competitor discovery, `domain_organic` for keyword
footprints. Each file states its own coverage and any reports that were blocked by
plan limits.

## Files

- `YYYY-MM-DD-semrush-competitor-gap.md` — one dated competitor/gap analysis per pull.
- `YYYY-MM-DD-onsite-crawl-comparison.md` — dated qualitative crawl comparing
  carlifebydani.com's page structure/format against the same competitor set
  (used when Semrush data is unavailable or to add a structural read alongside
  the keyword-gap numbers).
